How it scales

Production version

  • Replace sample data with Shopify Admin API orders/products.
  • Push generated segments into Klaviyo Lists/Segments and Flows.
  • Run the AI call server-side so no customer PII is sent to a browser.
  • Add priority/suppression rules so overlapping segments do not double-send.
  • Keep marketing approval before any campaign goes live.

Deliberate limits

What this demo does not do

  • No real customer data — the base is synthetic and seeded.
  • No sending: the app never writes to Klaviyo or dispatches email.
  • Revenue figures are transparent estimates, not forecasts.
  • Segmentation stays rule-based and testable; AI only writes copy.
